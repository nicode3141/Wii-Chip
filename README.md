# Wii-Chip

A rotating chip as ascii-art. Alternatively, you can upload your own ascii animations.
Displays any fromatted json stream as a ASCII video on the Wii.

### Demo

<img src="assets/preview.gif" alt="Wii-Chip Demo" width="300" height="200">

### Creating your own ASCII video file

you can convert a regular gif to a readable json file using my Project [FunWithAscii](https://github.com/nicode3141/FunWithAscii).

### Dependencies

- cJSON
- Wii (devkitPro)

### Notes

all assets are compiled into one executable (boot.dol)
